# The rules of the job filters of the continuous integration.
#
# One line per rule: the job that needs the paths, and the pattern of the
# paths. The pattern is the syntax of the filters of GitHub Actions:
#
#   *  matches any character, the slash except
#   ** matches any character, the slash included
#   ?  matches one character, the slash except
#
# The job named "all" is the machinery of the filters themselves: a change
# of the workflow, of the scripts of the continuous integration or of the
# dispatcher of the targets changes what every job proves, so every job
# runs.
#
# The rules are deliberately coarse. A path that is missing here skips a
# proof that the change needed; a path that is too wide only costs a run
# that was not needed. When in doubt, the wider rule is the safe one.

# The machinery of the filters: a change of any of these paths changes what
# every job of the workflow proves.
